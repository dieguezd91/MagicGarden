# Proyecto Final

A 2D garden-defense and survival game in Unity. [VERIFY NAME AND PITCH — concept inferred from code.] Plant, craft and cast spells to defend your house through day-night and lunar cycles, culminating in boss nights.

## Features
- **Day/night and lunar cycle** that influences gameplay (`LunarCycleManager`, `LunarInfluenceManager`, `WeatherController`)
- **Planting system** with attack, defense and resource plants
- **Crafting** (cauldron, recipe ScriptableObjects) and seed/material inventory
- **Spells** (melee, ranged, area, teleport) with mana system
- **Enemies** with state machines, plus boss nights and ritual altar
- **Tutorial system**, settings, music/sound managers, scene loading
- Data-driven with ScriptableObjects, object pooling, and event classes (`GameplayEvents`, `UIEvents`)

## Tech
Unity 2022.3.16f1 · C# · 2D URP · DOTween · Amplify Shader Editor · TextMesh Pro

## Run it
1. Open the `Proyecto-Final/` subfolder with Unity 2022.3.16f1.
2. Open `MenuScene` (or `GameScene`) and press Play.
